# Baby Growth Tracker — Releases

寶寶成長追蹤器的安裝檔與自動更新發佈處。原始碼在 private repo，這裡只放 [Releases](https://github.com/0100Light/baby-growth-tracker-releases/releases)。

- Windows：下載 `Baby-Growth-Tracker-Setup-x.y.z.exe`
- Linux：下載 `Baby-Growth-Tracker-x.y.z.AppImage`

已安裝的 app 會自動從這裡檢查並下載更新；請勿刪除 Release 內的 `latest.yml`、`latest-linux.yml` 與 `.blockmap` 檔。
